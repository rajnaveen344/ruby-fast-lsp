# Focused contributor workflows

These optional skills apply the shared [contributor guide](../AGENTS.md) to
specific tasks.

| Skill                                        | Use it for                                       |
| -------------------------------------------- | ------------------------------------------------ |
| [architecture](skills/architecture/SKILL.md) | Module placement, APIs, and state ownership      |
| [test](skills/test/SKILL.md)                 | Regressions, harness selection, and flaky tests  |
| [review](skills/review/SKILL.md)             | Correctness and maintainability review           |
| [performance](skills/performance/SKILL.md)   | A measured latency, indexing, or memory problem  |
| [ruby-index](skills/ruby-index/SKILL.md)     | Namespace tree, mixins, MRO, or graph navigation |
| [release](skills/release/SKILL.md)           | Candidate preparation, versions, and publication |

Keep each workflow narrow and operational. Link maintained guides instead of
copying them. Update a skill when its commands or source paths change; remove it
if it no longer describes a distinct workflow. Completed goals and session status
do not belong here.
